 — Portfolio

A React, TypeScript, and Vite portfolio highlighting AI/ML, Generative AI, and backend engineering work.

## Development

```sh
npm install
npm run dev
```

Run `npm run build` for a TypeScript check and production build, and `npm run lint` for ESLint.
